# Ines Grimaux - Artist Portfolio

Portfolio pessoal da artista Ines Grimaux. Apresenta trabalhos em fotografia, escultura, desenho e gestão cultural.

## Stack

- HTML5 / CSS3 / Vanilla JavaScript
- Responsive Design
- Self-hosted Fonts (Montserrat, EB Garamond)
- Open Graph / Twitter Card meta tags
- SEO optimizado

## Como rodar

```bash
npm install
npm run dev
```

Servidor inicia em `http://localhost:5500`

## Deploy

Deploy manual em servidor de produção.

```bash
npm run preview
```

Visualizar build localmente.

## Características

- Portfolio responsivo
- Integração Open Graph
- Twitter Cards
- Imagens otimizadas
- Self-hosted fonts para performance
